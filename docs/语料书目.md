# 拾遗 · 中国古典经典语料书目

《拾遗》是菜单栏语录卡片 app，每次弹出一条语录（正文 + `《书名》· 篇章`）。
本清单是扩展语料的选书结果，共 **67 本、7738 条**，每本都已作为独立 JSON
生成，可直接导入 app 的书库。

## 交付形态

app 的书库支持**导入任意语料 JSON**（托盘菜单 →「书库」→ 底部「导入书籍…」），
格式为：

```json
[
  {
    "id": "bj-1",
    "text": "一身精神，具乎两目；一身骨相，具乎面部。",
    "source": "《冰鉴》",
    "book": "冰鉴",
    "chapter": "神骨第一"
  }
]
```

因此物料 = **每本书一个 JSON 文件**，放在 `语料/` 目录（67 个文件 + `manifest.json`），
用户逐本导入即可，**不需要改 app 代码**。

导入时的校验由 app 自己完成（`src-tauri/src/corpus.rs` 的 `import()`）：
字段完整、id 唯一、正文非空、`source` 与 `book` 一致、书名不重复、内容指纹不重复。
`cargo test delivered_corpus_files_pass_import_checks` 会把 `语料/` 下每个文件
按同一套规则校验一遍，确保交付前就已经过得了 app 的关。

## 排版风格

风格基线取自 app 内置的 265 条语料（道德经 / 论语 / 庄子 / 孟子 / 传习录），
实测得到的硬约束，`scripts/check_style.py` 按同一套规则校验：

| 规则 | 说明 |
| --- | --- |
| 标点 | 只用全角（，。；：？！、），无半角逗号分号冒号问号叹号 |
| 引号 | 正文中不出现任何引号与书名号 |
| 括号 | 正文中不出现括号（内置 265 条里一个都没有）——括号里是校勘注、音释，属笺注不是正文 |
| 结尾 | 每条以「。」「？」「！」之一结尾 |
| 长度 | 6-90 字，中位数 16-20 字 |
| 篇章 | 用古籍原名（篇名 / 卷次 / 章节） |
| 简体 | 繁体来源（国语等）经 opencc 转简体 |

内置语料允许「子曰：」这类说话人前缀（论语有 3 条），但**不允许**剥掉引号后
剩下的光杆「曰：」——原文是「何谓量权？曰：“…”」，引号剥了就成了一句截断的话。
`scripts/normalize_corpus.py` 负责这一层归一。

## 已排除的书

以下书在 gushiwen 上有原文，但实测产出**不适合做语录卡片**，未纳入：

- **百家姓** — 438 章（每姓一章），只有姓氏，无可读句子
- **左传 / 战国策** — 编年纪事，条目是「夏五月，郑伯克段于鄢」这类事件记录而非名言
- **易传** — 卦爻辞断句零碎，大量条目语义不完整

## 工具

| 脚本 | 用途 |
| --- | --- |
| `scripts/fetch_quotes.py` | 从 gushiwen 抓取单本书原文并切分（含对话体/注记/半句过滤） |
| `scripts/build_corpus.py` | 批量抓取，生成 app 语料 JSON |
| `scripts/extract_chapters.py` | 从九五查询按章提取（`article` 容器，跳过序跋） |
| `scripts/extract_sections.py` | 从「原文/译文/注释」分栏页提取（古诗文网分则版） |
| `scripts/extract_cihua.py` | 《人间词话》专用提取（按则号切分，滤掉引文与夹注） |
| `scripts/extract_page.py` | 静态页提取（增广贤文） |
| `scripts/normalize_corpus.py` | 归一到内置语料的排版风格 |
| `scripts/split_corpus.py` | 把批量结果拆成「每书一个文件」+ manifest |
| `scripts/check_style.py` | 校验排版风格（引号 / 括号 / 半角标点 / 结尾 / 长度） |
| `scripts/validate_quotes.py` | 校验条数、id 唯一性、字段完整性（manifest 驱动） |

## 复现

```bash
# 抓取单本
python3 scripts/build_corpus.py --book "冰鉴:74e96e4ead90" --prefix bj --out /tmp/bj.json

# 批量抓取（gushiwen 限流较严，脚本内置退避重试）
python3 scripts/build_corpus.py --batch --out /tmp/corpus/all.json

# 归一 + 拆分 + 校验
python3 scripts/normalize_corpus.py --in /tmp/corpus/all.json --out /tmp/corpus/all.norm.json
python3 scripts/split_corpus.py --in /tmp/corpus/all.norm.json --out ./语料/
python3 scripts/check_style.py --dir ./语料/
cd src-tauri && cargo test delivered_corpus_files_pass_import_checks   # 过 app 自己的导入校验
```
